# 儿童游戏设计原则

## 体验原则

1. 单局 2–5 分钟，随时可以自然结束。
2. 不设置失败羞辱；错误只触发温和提示或有趣反馈。
3. 界面元素少而大，文字不是完成游戏的前提。
4. 声音柔和，默认音量保守，避免突然的高响度刺激。
5. 不依赖高速反应，不用倒计时制造焦虑。
6. 奖励强调发现、创造和故事变化，不依赖数字膨胀。
7. 允许重复，但每次只加入一点点变化。

## 安全与隐私

- 无广告、无公开聊天、无陌生人社交。
- 不收集真实姓名、生日、照片、声音、位置或通讯录。
- 家长设置区使用成人可理解的操作门槛。
- 网络功能默认关闭；将来如需联机，优先采用家庭私有房间。
- 存档优先保存在本地，并提供家长可控的导出与删除方式。

## 家长观察卡

每次试玩只记录三件事：

- 孩子主动重复了什么？
- 哪一步需要成人帮助？
- 玩多久后自然离开？

这些观察用来调整难度，不给孩子贴能力标签。
