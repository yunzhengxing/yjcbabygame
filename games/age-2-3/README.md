# 2–3 岁游戏包

这个阶段不追求“会玩电脑”。重点是亲子互动、感官探索和建立快乐的因果体验。每次只玩一个游戏，2–5 分钟即可。

## 1. 颜色小侦探

家长说一种颜色，孩子在房间里找到同色物品并指给家长。找到后，云朵伙伴发出一句简短祝贺。数字版只需要一个大色块和一个大按钮。

培养：颜色识别、注意力、现实环境探索。

## 2. 动物来敲门

播放一种温和的动物声音，孩子从两张动物卡中选出对应动物。答错时不出现红叉，而是再播放一次并让动物露出一小部分。

培养：声音辨别、联想和记忆。

## 3. 拍拍节奏

家长拍一次或两次手，孩子模仿；然后交换角色，让孩子出题。数字版用云朵闪烁和轻柔鼓点表达节奏。

培养：模仿、轮流、节奏和工作记忆。

## 4. 形状回家

把圆形、三角形和方形纸片送入对应轮廓。数字版采用大尺寸拖放，靠近目标时自动吸附。

培养：形状识别、手眼协调和分类。

## 5. 云朵藏猫猫

三个熟悉物品中有一个藏到云朵后面，让孩子猜少了哪个。初始只使用两个物品，熟悉后再增加。

培养：物体恒存、观察和简单记忆。

## 原型优先级

第一款建议做《颜色小侦探》：规则最简单，可以先验证孩子是否喜欢云朵伙伴、声音反馈和每局时长，再决定后续美术与技术方向。
