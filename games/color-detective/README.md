# 颜色小侦探（本地原型）

面向 2–3 岁孩子的低刺激颜色识别小游戏。

## 试玩

直接打开 `index.html`，或在仓库根目录启动任意静态文件服务器后访问：

`/games/color-detective/`

## 第二版玩法

- 三个等级：彩虹芽、云朵侦探、彩虹高手。
- 难度从 2 个色块、3 轮逐步增加到 4 个色块、6 轮。
- 启蒙等级保留彩色文字提示；更高等级使用中性文字，避免直接透露答案。
- 完成等级获得 1–3 颗星星，点错不扣星。
- 最近选择的等级和最高完成等级只保存在本机浏览器。
- 色块不显示颜色名称，孩子只根据颜色和语音进行判断。
- 点错时只给温和提示，不出现红叉或失败音效。
- 支持普通话语音提示，也可以关闭声音。
- 支持手机、平板和电脑浏览器。

## 隐私

这是纯本地网页，不联网、不存储信息、不采集任何儿童数据。
