# 熊孩子的游戏世界

这是一个会陪孩子一起长大的长期游戏项目。孩子现在 2 岁，现阶段以亲子互动、现实世界探索和极短时长的小游戏为主；等他能安全使用电脑后，再逐步发展成一个可探索、可创造、可持续扩展的数字游戏世界。

## 核心目标

- 快乐优先，不把游戏做成作业。
- 每个阶段只练一种或两种能力，反馈简单、温和、明确。
- 家长参与，但不要求家长一直教学。
- 不使用广告、抽卡、诱导付费、无限刷取或惩罚性连续登录。
- 默认保护隐私：不采集孩子的真实姓名、照片、声音、位置或行为画像。
- 每个小游戏都能独立玩，也能为未来的“游戏世界”积累角色、故事和物品。

## 年龄路线

| 阶段 | 主要形式 | 重点能力 | 示例 |
|---|---|---|---|
| 2–3 岁 | 亲子实体游戏、触摸与声音 | 因果、颜色、节奏、简单分类 | 找颜色、动物叫声、拍手节奏 |
| 3–4 岁 | 大按钮触屏游戏 | 拖放、配对、顺序、表达 | 给动物喂食、形状回家 |
| 4–6 岁 | 触屏与少量键鼠 | 规则、想象、数感、合作 | 小小厨房、积木城、寻宝 |
| 6–8 岁 | 键鼠与轻量冒险 | 阅读、规划、空间、创造 | 云朵村、机关岛、故事工坊 |
| 8–12 岁 | 开放世界与创作工具 | 系统思维、编程、协作 | 自动农场、任务编辑器、机器人伙伴 |
| 12 岁以上 | 共创与作品发布 | 设计、编程、叙事、责任 | 自制关卡、模组、家庭服务器 |
